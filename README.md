# AUPP Trading Club — Market Structure Presentation Deck

A presentation slide deck created for the **AUPP Trading Club** at the **American University of Phnom Penh**, teaching **Market Structure, Swing Mechanics, BOS, CHoCH, and Multi-Timeframe Analysis**.

Built with HTML5, CSS3, and JavaScript, strictly adhering to the official visual identity, typography (Cinzel & Montserrat), and color palette from the Week 1 Fundamentals deck.

---

## 🚀 How to Run & Present

### 1. Direct Browser Opening
Simply double-click or open `index.html` in any modern web browser (Google Chrome, Brave, Safari, Edge).
No web server or npm install required!

### 2. Live Local Server (Optional)
If you prefer running via a local web server:
```bash
npx serve Market_Structure
# or
python3 -m http.server 8000 -d Market_Structure
```

## ⌨️ Keyboard Shortcuts & Controls

| Key | Action |
|---|---|
| `→` / `Space` / `PageDown` / `J` / `L` | Next slide |
| `←` / `PageUp` / `K` / `H` / `Backspace` | Previous slide |
| `Home` | Jump to First Slide (Cover) |
| `End` | Jump to Final Slide (Q&A) |
| `F` | Toggle Fullscreen presentation mode |
| `G` | Open Slide Grid Overview modal |
| `P` or `Cmd+P` / `Ctrl+P` | Open Print Dialog / Export to PDF |
| `Escape` | Exit Fullscreen or close Overview Modal |

---

## 📄 How to Export to PDF (1440x810 16:9)

1. Open `index.html` in Google Chrome or your browser.
2. Click the **"Export PDF"** button in the bottom floating toolbar or press `P`.
3. In the Chrome Print Dialog:
   - **Destination**: Save as PDF
   - **Layout**: Landscape
   - **Margins**: None
   - **Options**: Check "Background graphics"
4. Click **Save** to generate a pristine, high-resolution PDF presentation!

## 📚 Curriculum Structure (19 Slides)

1. **Cover**: AUPP Trading Club Logo, Title, Subtitle, Institutional credentials
2. **What Is This?**: Retail Chaos vs Institutional Order (The Core Hook)
3. **Table of Contents**: 6 structured workshop modules
4. **Disclaimer**: Official club disclaimer matching Week 1
5. **Why Market Structure Is King**: Direction, Location, Invalidation
6. **The Three Market Phases**: Uptrend, Downtrend, Consolidation
7. **Bullish Market Structure**: Higher Highs (HH) & Higher Lows (HL) with vector chart
8. **Bearish Market Structure**: Lower Highs (LH) & Lower Lows (LL) with vector chart
9. **Break of Structure (BOS)**: Trend Continuation & Body Close vs Wick Sweep
10. **Change of Character (CHoCH / MSS)**: Trend Reversals & Failure Swings
11. **BOS vs CHoCH Master Comparison**: Side-by-side comparison table
12. **Strong vs Weak Structure**: Protected Institutional Lows vs Targeted Retail Highs
13. **Multi-Timeframe Structure (MTF)**: Fractality (4H Macro vs 15m Micro Entry)
14. **Liquidity Sweeps vs Real Shifts**: Spotting the "Turtle Soup" / Fakeout Trap
15. **Complete Execution Playbook**: 5-step institutional routine
16. **Spot The Structure! (Live Interactive Practice)**: Interactive quiz slide with live toggleable layers
17. **Golden Rules of Market Structure**: 4 commandments of trading structure
18. **The 3 Pillars Integration**: Reconnecting Strategy, Risk Management, and Psychology
19. **Q&A & Community Closing**: Discussion prompt and closing credits
